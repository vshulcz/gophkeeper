# Contributing

Thanks for your interest in improving GophKeeper.

## Development Workflow
1. Fork the repo and create a feature branch.
2. Run `go test ./...` before submitting a PR.
3. Keep changes focused and add tests where appropriate.

## Style
1. Go formatting is required (`gofmt`).
2. Keep public APIs documented.
3. Prefer small, composable changes.

## Reporting Issues
1. Provide exact reproduction steps.
2. Include OS, Go version, and logs if relevant.
